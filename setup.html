Chọn phong cách nhân vật

Nhân vật minh họa là học viên châu Á. Chọn trang phục để xem bản xem trước thay đổi trực tiếp.

Kéo ngang để xoay nhân vậtĐồng phục học viên
Khám phá câu hỏi gợi ý
Câu hỏi mẫu về nội quy

Đây là gợi ý xem trước. Khi tích hợp vào chat, các nút sẽ gửi câu hỏi qua hàm gửi tin nhắn hiện có.

BƯỚC 06 · AI CONFIGURATION

Kiểm tra cấu hình AI

Bước này không bắt buộc nếu bạn đã lưu API key trong tài khoản.

Không nhập API key nếu không cần thay đổi. API key được lưu trong Firestore vẫn có thể bị truy cập nếu Rules cấu hình sai; với triển khai nhiều người dùng, nên chuyển việc gọi mô hình sang backend có xác thực.
